Geo Sleuth.

Находит место съёмки фотографии и показывает, как к этому пришёл. Иногда с точностью до пары метров.

Как это работает

Геометрия вместо догадок

Одно фото, одна фразаДайте агенту снимок и скажите «найди, где это снято». В ответ придут координаты точки съёмки, направление камеры и спутниковое изображение-доказательство.
Работает без надписейДаже без вывесок, номеров и ориентиров поиск ведут геометрия OpenStreetMap, данные о рельефе, спутниковые снимки и Street View.
Каждый вывод подкреплён файломВывод обязан ссылаться на команду, которую агент запустил, и на файл, который она создала. Известность места доказательством не считается.
Скрипты ранжируют, модель судитОколо двадцати скриптов ищут, оценивают и сортируют варианты, а модель выбирает только среди лучших нескольких.
Ответ с радиусом ошибкиКоординаты ± радиус, курс камеры, изображение-доказательство и уровень уверенности.
Один навык для всех агентовЭто стандартный SKILL.md и обычные Python-скрипты. Работает в Claude Code, Codex, Cursor, Gemini CLI, OpenCode и GitHub Copilot.

Установка

Две минуты и одна команда

Нужен Python 3.10+. При первом запуске попросите агента выполнить doctor.py из папки scripts/: он проверит зависимости и доступ к сети.

Через skills CLI

Выберите агентов, когда CLI спросит.

npx skills add Danlug/Geo-Sleuth

Вручную, для Claude Code

Скопируйте папку навыка в каталог навыков.

git clone https://github.com/Danlug/Geo-Sleuth
cp -r Geo-Sleuth/skills/geo-sleuth ~/.claude/skills/

Потом дайте агенту фото и напишите: «найди, где снято это фото».

Веб-версия

Без установки, прямо в claude.ai

Загрузите фото, и Claude разберёт подсказки, предложит кандидатов с координатами и радиусом ошибки и подскажет, как проверить ответ. Работает только по самому изображению, без OSM- и спутниковых инструментов навыка.
